About the Project

This is a personal game development project created using the Processing programming language. The software is currently a work in progress, with several minor bugs still being addressed. For example, the ball can occasionally pass through the paddle and score even when the two appear to be in contact.

The fire symbol in the center of the screen acts as a power-up. When the ball hits the symbol, it is launched across the screen toward the paddle that did not last hit the ball, adding an additional gameplay mechanic.

There are many possibilities for expanding the game and making it more engaging. Future improvements could include additional power-ups, such as Freeze Ball and Freeze Paddle, as well as an AI opponent to enable single-player gameplay. I could also develop the game into a standalone application and make it publicly accessible. There are many possibilities for this project, and I look forward to continuing its development.

LED Pattern Display

A device that lights up a series of LEDs in a pattern (January 2022 - April 2022)

About the Project

This was one of the activities I completed for the course Computer Organization (ENCM 369) at the University of Calgary. I used the C programming language to create an LED pattern, which was stored in an array.

A for loop iterates through the array with a delay of 1 microsecond between each pattern, controlling the amount of time each LED pattern is displayed. This project used a PICkit microcontroller and MPLAB to compile and run the C code.

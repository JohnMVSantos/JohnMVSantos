About the Project

This is a personal project that was inspired by the E.D.I.T.H Glasses seen in Spider-man No Way Home. This project uses a LilyGo TTV that is built with ESP32 and OLED transparent screen. The display can be programmed using Arduino. This project is a work in progress. Currently, it shows the date and the time. However, future additions will include weather information. Problems with the device is that the text cannot be seen up close upon wearing the glasses, so a convex lens is needed to allow the text to be seen as if it is from a distance. A full implementation of this product could be used as a GPS navigator.

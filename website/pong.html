PONG

A game named PONG that is inspired by the
ATARI Game back in the 70’s.

About the Project

This is a personal project using the language Processing. The software that I have developed to create this game is still a work in progress. There are minor bugs where the ball still manages to escape the paddle and score even though both were in contact. The fire symbol in the middle is a powerup; if the ball hits the symbol, the ball will shoot across the screen attacking the paddle that did not hit the ball last. Furthermore, there are lots of ways to make the game more fun; I can add more powerups (Freezeball, Freezepaddle, etc), I can even add an A.I. and make it single player playable. Lastly, I can make the game accessible to the public by making an application for the game. There are lots of possibilities in this project that I can’t wait to work on.
